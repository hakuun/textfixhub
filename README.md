# TextFixHub

Free browser-based text tools for everyday writing, editing, and content work.

TextFixHub provides simple utilities for alphabetizing lists, removing broken
line breaks, counting sentences and text statistics, and generating random
text. The tools run directly in your browser and do not require an account.

## Live Website

[TextFixHub](https://www.textfixhub.com/)

## Available Tools

- [Alphabetizer](https://www.textfixhub.com/tools/alphabetizer) — sort lists alphabetically
- [Line Break Remover](https://www.textfixhub.com/tools/line-break-remover) — clean broken line breaks from copied text
- [Sentence Counter](https://www.textfixhub.com/tools/sentence-counter) — count sentences, words, characters, paragraphs, and reading time
- [Random Sentence Generator](https://www.textfixhub.com/tools/random-sentence-generator) — generate random sentences from a hand-written sentence library
- [Random Noun Generator](https://www.textfixhub.com/tools/random-noun-generator) — generate random nouns for brainstorming and games

## Privacy

TextFixHub processes text locally in the browser using JavaScript. User input
is not uploaded to a remote server or stored in a database.

## Technology

- Next.js
- TypeScript
- Tailwind CSS
- Browser-side JavaScript
- Static deployment on Vercel
